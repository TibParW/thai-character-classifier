# Thai Consonant Character Classifier (Data Science Capstone Project)
### แบบจำลองและการจำแนกพยัญชนะภาษาไทย 44 รูป (ก - ฮ) ด้วยกระบวนการวิทยาศาสตร์ข้อมูล

---

## 1. แนวคิด ปัญหาที่ต้องการแก้ และประโยชน์ในการนำไปใช้ (Concept & Problem Statement)

### 1.1 ที่มาและปัญหา (Problem)
ภาษาไทยประกอบด้วยพยัญชนะทั้งหมด 44 รูป (ก ถึง ฮ) ซึ่งมีสัณฐานวิทยาของตัวอักษรที่มีความซับซ้อน ลายเส้นมีความคล้ายคลึงกันในหลายคู่ เช่น การมีหรือไม่มีหยัก (ข กับ ช, ฎ กับ ฏ), ความยาวของหาง (บ กับ ป, ผ กับ ฝ, พ กับ ฟ), และทิศทางการม้วนหัว (ด กับ ต, ถ กับ อ) การพัฒนาแบบจำลอง Machine Learning ให้สามารถแยกแยะพยัญชนะไทยได้ถูกต้องจึงเป็นโจทย์ที่มีความท้าทายสูง

### 1.2 ประโยชน์ของเว็บแอปพลิเคชัน (Applications & Benefits)
- **ระบบแปลงเอกสารสแกนและลายมือเป็นข้อความดิจิทัล (Optical Character Recognition - OCR):** นำไปต่อยอดใช้ในงานแปลงเอกสารราชการ ทะเบียนราษฎร์ หรือบันทึกเวชระเบียน
- **ระบบอ่านป้ายทะเบียนรถยนต์อัตโนมัติ (Automated License Plate Recognition - ALPR):** ช่วยตรวจจับหมวดอักษรบนป้ายทะเบียนรถยนต์
- **สื่อการเรียนการสอนภาษาไทย (Educational Application):** ให้เด็กหรือชาวต่างชาติฝึกเขียนพยัญชนะไทยบนหน้าจอ และระบบสามารถตรวจทานให้ผลย้อนกลับ (Feedback) แบบเรียลไทม์ได้ทันที

## 2. แหล่งที่มา จำนวนข้อมูล และการแบ่งชุดฝึก/ชุดทดสอบ (Dataset & Data Splitting)

### 2.1 แหล่งที่มาของข้อมูล (Data Sources & Fusion)
ชุดข้อมูลเป็นการผสานรวม (Data Fusion) ทั้งสองโดเมนเข้าด้วยกัน:
- **ลายมือคนเขียนจริง (Handwritten Characters):** รวบรวมภาพพยัญชนะไทยจากการเขียนจริงหลากหลายลายมือ
- **ตัวพิมพ์คอมพิวเตอร์หลากหลายฟอนต์ (Printed Fonts 14 แบบ):** สร้างภาพตัวพิมพ์จากฟอนต์ยอดนิยม ได้แก่:
  - ฟอนต์ทางการ/มีหัวดั้งเดิม: *Sarabun (Regular & Bold), Angsana New, Browallia New, Cordia New*
  - ฟอนต์มาตรฐานคอมพิวเตอร์: *Tahoma (Regular & Bold), Leelawadee UI (Regular & Bold)*
  - ฟอนต์โมเดิร์น/ไม่มีหัว: *Kanit (Regular & Bold), Prompt, Chonburi*
- พร้อมการทำ **Data Augmentation** (หมุน $\pm 14^\circ$, เลื่อนพิกเซล, ปรับขนาด, จำลองเส้นปากกาหนา-บาง)

### 2.2 จำนวนข้อมูลและความสมดุล (Dataset Size & Balance)
- **จำนวนคลาส:** 44 คลาส (พยัญชนะ ก ถึง ฮ)
- **จำนวนภาพต่อคลาส:** 500 ภาพต่อคลาส (สมดุล 100%)
- **จำนวนภาพรวมทั้งสิ้น:** **22,000 ภาพ** (คิดเป็น ~44% ของชุดข้อมูลตัวอักษรเดี่ยวทั้งประเทศ)

### 2.3 การแบ่งชุดฝึกสอนและชุดทดสอบ (Train/Test Split)
เพื่อป้องกันปัญหา Data Leakage และ Overfitting:
- **Training Set (80%):** 17,600 ภาพ (400 ภาพต่อคลาส) สำหรับให้โมเดลฝึกเรียนรู้
- **Test Set (20%):** 4,400 ภาพ (100 ภาพต่อคลาส) ซ่อนไว้สำหรับวัดผลการทำนายจริง
- **การแบ่งแบบ Stratified Sampling:** กำหนดสัดส่วน 80:20 เท่ากันทุกคลาสโดยใช้ `random_state=42`

## 3. ขั้นตอนการเตรียมภาพและสกัดคุณลักษณะ (Preprocessing Pipeline)

ภาพที่รับเข้าสู่ระบบ (ทั้งจากชุดข้อมูลและการอัปโหลดผ่านเว็บ) จะผ่านกระบวนการเดียวกันตามลำดับ:
1. **Grayscale Conversion:** แปลงภาพเป็นภาพขาวดำ 1 แชนแนล (Single Channel)
2. **Foreground/Background Standardization:** ตรวจสอบค่าเฉลี่ยความสว่าง หากพื้นหลังเป็นสีขาวจะทำการ Invert สีเพื่อให้ **เส้นหมึกเป็นสีขาว (พิกเซล > 0)** และ **พื้นหลังเป็นสีดำ (พิกเซล = 0)** ตามมาตรฐานสากล
3. **Auto-crop Bounding Box:** ตรวจหากรอบล้อมรอบตัวอักษรจริงเพื่อตัดขอบว่างภายนอกออก
4. **Centering & Resizing:** ปรับขนาดตัวอักษรให้อยู่ในกรอบ 20×20 พิกเซล โดยรักษาสัดส่วนภาพเดิม (Aspect Ratio) แล้วนำไปวางไว้กึ่งกลางภาพขนาด 28×28 พิกเซล
5. **Pixel Normalization:** ปรับสเกลค่าพิกเซลให้อยู่ในช่วง $[0, 1]$

## 4. แบบจำลอง ผลการประเมินหลัก และการวิเคราะห์ข้อผิดพลาด (Model & Evaluation)

### 4.1 เปรียบเทียบแบบจำลอง Machine Learning & Deep Learning

| แบบจำลอง (Model) | สถาปัตยกรรม / พารามิเตอร์ | เวลาฝึกสอน (Ryzen 5 5600X) | Test Accuracy (4,400 ภาพทดสอบ) | Macro F1-Score | จุดเด่น |
| :--- | :--- | :---: | :---: | :---: | :--- |
| **🧠 Deep CNN (โมเดลหลัก)** | 3 Conv Blocks + BatchNorm + Dropout | **9.25 นาที** | **99.14% 🚀** | **0.9912** | **แยกได้ขาดลอย ทั้งตัวพิมพ์และลายมือ** มั่นใจระดับ 99.8%-100% |
| **⚡ Random Forest** | `n_estimators=200`, `n_jobs=-1` | **1.69 วินาที** | **92.64%** | **0.9258** | เทรนเร็วมาก ใช้เป็น Baseline ตามวิชา |
| **Support Vector Machine** | RBF Kernel, `C=10`, `StandardScaler` | 6.21 วินาที | 88.18% | 0.8827 | โมเดลคลาสสิกตามแล็บ |

### 4.2 การแปลผลและความหมายของเมตริก
- **Accuracy (99.14%):** อัตราส่วนความถูกต้องของการทำนายพยัญชนะไทยทั้ง 44 คลาส บนชุดทดสอบขนาดใหญ่ 4,400 ภาพ (ทายถูกมากกว่า 4,360 ภาพจาก 4,400 ภาพ)
- **Macro F1-Score (0.9912):** คำนวณค่าเฉลี่ยฮาร์โมนิกของ Precision และ Recall โดยให้น้ำหนักทุกคลาสเท่าเทียมกัน ยืนยันว่าโมเดลทำนายได้ดีสม่ำเสมอทุกพยัญชนะ
- **การแก้ปัญหาคู่คล้าย (Morphological Discrimination):**
  - `ข (ข ไข่)`: ลายมือคนเขียนจริง ทายถูกต้อง **99.84%**
  - `ก (ก ไก่)`: ลายมือคนเขียนจริง ทายถูกต้อง **99.99%**
  - `บ (บ ใบไม้)`: ลายมือคนเขียนจริง ทายถูกต้อง **99.99%**
  - `ป (ป ปลา)`: ตัวพิมพ์ ทายถูกต้อง **100.00%**
  - `ฮ (ฮ นกฮูก)`: ลายมือคนเขียนจริง ทายถูกต้อง **100.00%**

## 7. วิธีใช้งานเว็บแอปพลิเคชัน (How to Use)

1. **เลือกภาพตัวอย่าง (Examples):** สามารถคลิกเลือกภาพตัวอย่างที่มีให้ด้านล่างของหน้าเว็บ (เช่น ก, ด, ป, ฮ)
2. **อัปโหลดภาพ (Upload Image):** อัปโหลดภาพถ่ายพยัญชนะไทย หรือภาพที่วาดจากโปรแกรม Paint
3. **ผลการทำนาย (Prediction):**
   - ด้านขวาบนจะแสดง **ผลการทำนาย 5 อันดับแรก (Top-5 Probabilities)** เช่น `ก (ก ไก่): 84.00%`
   - ด้านขวาล่างจะแสดง **ภาพขนาด 28 × 28 พิกเซล** ที่ผ่านกระบวนการ Preprocessing เพื่อให้ผู้ใช้เห็นว่าโมเดลประมวลผลภาพในลักษณะใด
